# Orbura AutoScientist Data Visualization Model

## Model Details

- **Base model:** Qwen2.5-1.5B-Instruct (or AutoScientist-selected equivalent)
- **Fine-tuning method:** Supervised fine-tuning via [AutoScientist](https://adaptionlabs.ai) (Adaption)
- **Dataset:** Orbura AutoScientist Data Visualization Dataset (10k train + 2k val, augmented)
- **Task:** Data visualization — matplotlib code generation, chart QA, code-to-description, style transfer, and bug repair
- **Competition:** AutoScientist Challenge Part 2 — Data Visualization

## Training

- **Train examples:** 10,000 (augmented via Adaption Adaptive Data)
- **Validation examples:** 2,000 (held-out, deterministically generated)
- **Recipe:** AutoScientist co-optimized SFT recipe
- **Augmentation:** reasoning traces + deduplication (prompt rephrase disabled to preserve prompt fidelity)
- **Dataset generated by:** `generate_full.py` + Adaption augmentation

## Evaluation

The eval harness (`eval_finetuned.py`) scores per-task and overall using
deterministic structural metrics:

| Task | Scoring method |
|---|---|
| `chart_qa` | Exact or numeric-tolerance match |
| `chart_to_code` / `data_to_code` | Chart function + data value overlap (≥80%) |
| `code_to_desc` | Chart type + ≥2 numeric mentions |
| `style_transfer` | Normalized code equivalence |
| `fix_code` | Normalized code equivalence |
| `chart_choice` | First-word (chart type) match |

Run the eval yourself:
```bash
# Naive baseline (no model)
python3 eval_finetuned.py --baseline-only

# Base model vs fine-tuned
python3 eval_finetuned.py --baseline Qwen/Qwen2.5-1.5B --finetuned path/to/model

# Quick 50-sample test
python3 eval_finetuned.py --baseline-only --max-samples 50
```

## Usage

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("Papajams/orbura-dataviz-model")
tokenizer = AutoTokenizer.from_pretrained("Papajams/orbura-dataviz-model")

messages = [{"role": "user", "content": "Write Python matplotlib code for a bar chart.\n\n- A: 45\n- B: 78\n- C: 23"}]
text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
inputs = tokenizer(text, return_tensors="pt")
output = model.generate(**inputs, max_new_tokens=256)
print(tokenizer.decode(output[0], skip_special_tokens=True))
```

## Limitations

- Trained on synthetic chart data with 4 chart types (line, bar, scatter, pie).
  Performance on novel chart types (boxplot, heatmap, violin) is not validated.
- The text-only dataset does not test visual chart reading. The multimodal pilot
  (100 rows) begins to address this but is too small for full training.
- Generated matplotlib code uses a constrained style (grid, rotation,
  tight_layout). Real-world code style may differ.
- Always validate generated matplotlib code before execution.

## Reproducibility

```bash
# 1. Generate the dataset
python3 generate_full.py
python3 prepare_adaption.py

# 2. Run Adaption augmentation
python3 run_adaption.py --input data/adaption_train_10k.jsonl

# 3. Train via AutoScientist (adaptionlabs.ai/auto-scientist)
#    Upload the augmented dataset, select base model, run co-optimization

# 4. Evaluate
python3 eval_finetuned.py --baseline Qwen/Qwen2.5-1.5B --finetuned path/to/model

# 5. Publish
python3 publish_hf.py --model path/to/model --dataset-only
python3 publish_kaggle.py --model path/to/model --dataset-only
```
